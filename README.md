# Holoarquivo · Star Wars Saga Edition

Biblioteca de RPG com busca nas regras, leitor PDF, importação, edição e exportação de fichas, galeria e caderno do mestre.

**Site:** https://rpersolli.github.io/star-wars-arquivo-local/#inicio

## Executar localmente

Com Node.js instalado, execute `node server.cjs` ou abra `Iniciar.cmd`. Para dispositivos na mesma rede, use `Iniciar-na-rede.cmd`.

## Publicação

GitHub Pages publica a pasta `site` da branch `main` por meio do workflow `.github/workflows/pages.yml`. A branch `1.0.0` guarda a primeira versão publicada.

O site é público e pode ser aberto por qualquer pessoa que descubra o endereço. Não possui autenticação. Fichas importadas, notas, favoritos e configurações são individuais por navegador e não são enviados ao GitHub. Exporte seus PDFs e notas para backup.

Consulte `LEIA-ME.md` para instruções e limites e `VERIFICACAO.md` para as verificações da versão local. Star Wars e os materiais originais pertencem aos respectivos titulares. Projeto pessoal, sem vínculo oficial.
